# 校异斋 · 多版本文本自动比对与人工校勘工具

面向古籍和长文本编辑的多版本校勘工作台。可导入同一作品的不同版本，自动按段落与句子对齐，再由人工修正错位、判断增删改并导出校勘记。

## 功能

- 选择一份底本和两份参校本，底本分别与两本对齐后合并到同一条三家记录，三栏保留各自原文。
- 自动标出三家一致、两家多数一致、仅一家不同的孤例、三家互异和各家缺句；对齐按 24 个句段一组让出浏览器主线程。
- 比较规则可忽略标点或常见异体字；规则变化会重算相似度、多数/孤例判断和疑错位状态，不改写三份原文。
- 人工可分别移动底本、参校本一、参校本二的邻近配对，也可整条移动；手动类别、调序和定本依据都会进入撤销历史。
- 点选记录后可指定定本采用哪一家；多数读法可直接接受，孤本异文和三家互异读法必须人工确认，缺句可按实际补入校记。
- 每条差异可填写校勘说明和来源；可勾选批量接受多数建议、一键接受全部可自动采用建议，孤例与未定读法会保留待确认。
- 支持跳转到下一处未接受读法，以及键盘操作：`Alt+↓` 下一处、`A` 接受勾选、`Ctrl/⌘+Z` 撤销、`Ctrl/⌘+Y` 或 `Ctrl/⌘+Shift+Z` 重做。
- 最多保留 50 步撤销历史，三份版本、比较规则、对齐行、人工调序、定本选择、接受状态、校记和当前位置自动保存在 `localStorage`。
- 导出的 Markdown 校勘记和完整 JSON 数据均包含三份原文依据、多数/孤例/缺句标记、定本来源与接受状态。
- 桌面三栏工作区，窄屏自动堆叠；提供读屏可识别的表头、标签、状态与按钮名称。

## 技术栈

- Vue 3 + Vite + TypeScript
- Arco Design Vue 2
- 浏览器 localStorage
- 无后端服务，全部计算在浏览器本地执行

## 本地开发

```bash
npm install
npm run dev
```

打开终端显示的 Vite 地址。源码未硬编码宿主端口。

## 生产构建

```bash
npm install
npm run build
```

类型检查和生产产物会生成到 `dist/`。可用 `npm run preview` 预览。

## Docker

```bash
docker build -t sologsb-1023 .
docker run --rm -p 10023:80 sologsb-1023
```

容器内 nginx 监听 `80`，根据根端口表映射到宿主 `10023`。

## 数据说明

版本正文、对齐结果、校勘说明和撤销记录均保存在当前浏览器。清除站点数据会删除草稿，建议定期导出 JSON 或 Markdown 校勘记。
